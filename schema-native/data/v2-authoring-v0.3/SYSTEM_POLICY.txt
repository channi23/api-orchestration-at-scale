Select one tool from the supplied catalog and return exactly one JSON object with keys "tool" and "arguments". Return no wrappers or commentary.
Use the tool descriptions and raw JSON Schemas to map the user's request to the appropriate tool and arguments. Preserve all requested details that the tool can represent.
Include required argument structure and the values supplied by the request or documented conventions. Omit optional fields the request does not ask for. Do not insert an optional field merely because the schema supplies a default. Do not invent missing values.
Preserve string contents and the listed order of array elements. Object-key order has no significance. Return numbers as numbers and booleans as booleans; do not coerce between them.
When the request supplies a field's string value, preserve it exactly, including case. Do not substitute a synonym or a differently cased alias. For semantic mappings to an enum, use the schema's declared enum value. No alternative string aliases are accepted in this provisional contract; any later exception must be versioned and reviewed before model evaluation.
